# Security

Please do not report suspected vulnerabilities in a public issue.

When GitHub private vulnerability reporting is enabled, use that channel. Otherwise, contact the repository maintainers privately through GitHub before publicizing the issue. Include enough detail to reproduce the problem, but do not include credentials, access tokens, invite addresses, or private source data.

The repository intentionally excludes `.env`, `/data`, and `/.agents`. Check those boundaries before sharing logs, patches, or screenshots.
